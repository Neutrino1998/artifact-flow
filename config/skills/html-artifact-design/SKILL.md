# HTML Artifact 设计指导

以一个小工作室设计主管的姿态做每一页:为眼前这个主题做**特定的**配色、字体、
版式决策,避免"哪个项目都能用"的模板腔。

## 先读需求,校准投入

设计投入分档,但**每一档都要下功夫**——文档和落地页值得同样的手艺,变的只是
表现形式:

- **实用档**(计划、纪要、说明、演示页):要有真正的排版层级、考究的间距、
  一套选过的配色;但克制——大多数页面不需要巨幅 hero 和满屏动效。
- **编辑档**(落地页、宣传页、要送出去的成品):客户要的是有观点的设计。
  开场就是论点——用主题世界里最有性格的东西开头;敢在**一处**下重手,
  周围全部收静。
- 拿不准时:一个排版扎实的"普通"页面永远不出错,过度设计有时会。

## 本平台的硬约束(与外界教程不同,先记住)

前端把 `text/html` artifact 渲染成**静态页**:

- **script 与外部资源(CDN JS/字体/远程图片)一律不加载**——不要写 JS 交互,
  不要 `<link>` 外部字体;交互只用 CSS 能力(`<details>`、`:hover`、`:target`)。
- 图片用内联 `<svg>` 或 `data:` URI;字体只用系统字体栈。
- 一个文件自包含:所有 CSS 内联在 `<style>` 里。

## 每一页都适用的基本功

- **扎根主题**:先钉住一个具体主题、它的受众、页面的单一任务。独特的设计
  决策来自主题自己的世界(它的材质、器物、行话)。全程用真实内容,禁 lorem。
- **字体成对**:标题一个有性格的显示字体、正文一个互补字体,必要时加一个
  等宽字体管数据。中文系统栈:雅黑(现代)/宋体(端正)/楷体(人文),
  与 Georgia/等宽拉丁字体搭配。正文行宽 ~65 字符;定一套字号阶梯并守住;
  标题 `text-wrap: balance`,大写拉丁标签加 letter-spacing。
- **中性色也要"选"出来**:纯 #888 灰是没想过的灰;向页面强调色方向偏一点
  色相的灰才是选过的。纯白/近黑做底没问题——重点是"选的",不是"默认的"。
- **间距交给布局**:兄弟元素用 flex/grid + `gap`,不用会互相塌陷的逐元素
  margin。宽内容(表格/代码/图)自己包 `overflow-x: auto`,页面主体永不横滚。
  数字对齐的列上 `font-variant-numeric: tabular-nums`。
- **避开 AI 味聚集区**(用户点名要的除外——用户的话永远优先):米色底 + 衬线
  大标题 + 赤陶色点缀;近黑底配一个荧光绿/朱红;紫蓝渐变 hero;emoji 当章节
  标记;所有东西居中;满屏 `rounded-lg` 圆角卡 + 左侧彩条。没被指定方向时,
  别把自由花在这些默认值上。
- **文案即设计材料**:站在屏幕另一侧命名(用户管理的是"通知",不是"回调
  配置");主动语态;按钮写清会发生什么;报错说清哪儿错了、怎么修。具体胜过
  俏皮。
- **结构必须编码信息**:编号(01/02/03)、eyebrow、分隔线、标签,只在内容
  真有那个结构时用——内容真是序列才编号,不是拿来装饰的。
- **做的是工具/看板而非文档时**,手艺从排版转向信息设计:摘要先于明细;
  状态用形状编码(pill/chip/色条)让该注意的一眼跳出;语义色(好/警告/危险)
  独立于强调色,不算你的 accent;图表和文字同等用心(面积填充、淡网格、
  强调端点);可交互的要长得可交互(本平台 = CSS 交互)。
- **写干净**:注意选择器优先级互相打架(`.section` 和 `.cta` 抢间距)、
  级联静默互相抵消;闭合所有非空元素;尊重 `prefers-reduced-motion`。

## 动手前的流程

写码之前先落一个简短的设计计划,并全程照着推导:

1. **色**:4–6 个命名 hex(底、墨、强调、中性×2),说一句为什么配这个主题;
2. **字**:2+ 角色的字体(显示/正文/数据),中文拉丁各自的栈;
3. **版式**:一两句话的布局概念(如"左轨目录 + 右侧长文,数据卡穿插")。

编辑档多一步:对着主题复查这份计划——任何一部分若"换个主题也能用",就改掉
那一部分再动手。
