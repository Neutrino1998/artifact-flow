# PPTX 设计与排版方法论

做 slide 时先像设计负责人一样判断:这页在整套 deck 里承担什么功能,然后再选版式。
不要从“能塞下多少文字”开始。

## 基本原则

- 一页只讲一个论点。标题写结论,不要写“背景介绍”“方案说明”这类空标题。
- 每页必须有视觉角色:大数字、流程、对比、图表、截图、结构图、关键引语、留白层级之一。
- 连续页面要变换节奏:封面/章节页/双栏/数据页/流程页/对比页/结尾页交替使用。
- 正文左对齐;居中只给封面、章节页、结尾页、短口号。
- 文本框宁可少字也不要顶边。长标题缩短,长正文拆页。
- 图表服务结论:先写“想让观众看出什么”,再决定柱状/折线/面积/散点/表格。

## 配色

配色要贴主题,不要默认蓝。先确定一组 token:

- `primary`: 60-70% 的视觉存在感,用于标题、主背景、主图形。
- `secondary`: 支撑色,用于浅底、分区、次级图形。
- `accent`: 只点睛,用于数字、强调线、小标签。
- `text`: 正文色,通常近黑但可向主题色轻微偏移。
- `muted`: 注释、坐标轴、脚注。

一页里不要让三种彩色平均分权。若强调色到处都是,它就不再强调。

## 字体与层级

- 标题 30-44pt,正文 14-18pt,注释 10-12pt。
- 中文优先用微软雅黑/宋体/楷体等用户机器常见字体;不要假设有外部字体。
- 同一级标题字号、粗细、颜色要稳定。
- 数据页使用等宽或 tabular 风格的数字感;小数位和单位要统一。

## 常见版式

| 内容类型 | 推荐版式 |
|---|---|
| 开场主张 | 深色封面 + 大标题 + 一句副标题 |
| 章节切换 | 章节号/短标题/大留白 |
| 三到五个要点 | 图标行、卡片网格、左右分栏 |
| 前后对比 | 左右对照、差异高亮、箭头过渡 |
| 流程/阶段 | 横向时间线、编号步骤、泳道 |
| 数据结论 | 大数字 + 小图,或图表 + 右侧解读 |
| 风险/问题 | 分级矩阵、热力列表、红黄绿状态 |
| 方案架构 | 分层框图、输入-处理-输出、闭环图 |

## 避免 AI 味

- 不要连续多页“标题 + 5 条 bullet”。
- 不要用无意义装饰线,尤其是标题下横线。
- 不要每个元素都放圆角卡片;卡片必须表达分组。
- 不要过度渐变、发光、阴影;一处强表现足够。
- 不要把 emoji 当图标系统。
- 不要为了填满画面而加无信息图形。

## 数据页

- 表格只用于查数;讲故事优先用图。
- 单页只强调一个数据结论,其余数据退成辅助。
- 图表标题写结论,例如“高风险问题集中在鉴权与输入校验”,不是“风险分布”。
- 轴标签、单位、时间范围必须可读。
- 图表颜色必须和 deck token 一致,不要 matplotlib 默认色。

## 模板编辑时

- 先识别模板的设计语言:主色、标题位置、卡片/图标样式、页边距、页脚。
- 内容少于模板槽位时,删除整个槽位对应的视觉组;不要只清空文字。
- 内容多于模板槽位时,拆页或换版式;不要挤压字号。
- 如果替换文案导致标题换行,检查所有跟标题绑定的线条、图标、标签是否仍对齐。
