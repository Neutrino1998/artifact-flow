# 渲染验收

本检查用于已经生成的 HTML、SVG 或 PNG。静态检查始终执行；实际成图的视觉验收只在
当前部署具备渲染和识图能力时执行。不要为了满足本检查而要求部署新增浏览器、Node 或
视觉模型。

## 能力分流

- 能渲染且能识图时，打开实际输出；静态 HTML 检查常规宽度和约 360px 的窄屏，只有
  交付物声称同时支持深浅色时才检查两种主题。PNG 按最终嵌入尺寸查看，不能只看放大图。
- 无法渲染或识图时，检查源码、数据映射和下列结构约束后正常交付，同时明确说明未完成
  视觉验收。不得因此拒绝交付，也不要宣称已经检查渲染结果。
- 复用模板但替换了长文本、数据范围或系列数量时，只重新检查受影响的图；不要为未受影响
  的内容重复全量验收。

## 布局与可读性

- 标题、坐标轴、单位、图例、直接标签和关键 mark 不得重叠、裁剪或跑出绘图区。
- 先减少次要标注和刻度，再换行或重排；不要靠缩到 11px 以下解决拥挤。
- 长类别名优先横向条形或换行。小多图在窄屏纵向堆叠，不把整组固定宽度图直接缩小。
- 响应式 SVG 使用合适的 `viewBox` 和容器宽度。若静态 SVG 无法在窄屏保持文字可读，
  可以让图表自己的容器横向滚动；页面主体不能整体横滚。
- 表格可以在自己的容器内横向滚动；卡片内部不要形成难发现的双向滚动区域。

## 数据与语义

- 抽查关键 mark、直接标签、tooltip/title 与等价表格中的数值一致；缺失值不能默认为零。
- 柱图从零基线开始；对数轴、指数化序列或截断范围必须在轴或副标题中明确标识。
- 系列顺序变化后颜色身份保持不变；图例、直接标签、线型或纹理与图中 mark 一一对应。
- 标题说明指标、粒度和时间范围，轴写单位；状态色带有文字或形状等第二编码。

## 交付判断

交付前必须解决静态可确认的问题：数据与标签一致，palette `FAIL` 已修正，`WARN` 有第二
编码，静态 HTML 自包含且有紧凑表格等价视图。视觉验收可用时，修正实际观察到的缺字、
碰撞、裁剪和页面级横向溢出后再交付；不可用时，完成静态检查并披露限制即可交付。视觉
能力缺失本身不是失败条件。
