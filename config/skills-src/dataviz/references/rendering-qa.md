# 渲染验收

本检查用于已经生成的 HTML、SVG 或 PNG。它验证实际成图；不能用源码审阅或 palette
validator 代替。按风险选择最小检查范围，不必为未受影响的图重复全量验收。

## 检查范围

- 打开实际输出，而不是只看生成代码。无法预览时，做静态检查并明确说明未完成视觉验收，
  不要宣称已经检查渲染结果。
- 静态 HTML 至少检查常规宽度和约 360px 的窄屏；只有交付物声称同时支持深浅色时，
  才需要两种主题都检查。
- PNG 按最终嵌入尺寸查看，不能只在放大状态下判断可读性。复用模板但替换了长文本、
  数据范围或系列数量时，重新检查受影响的图。

## 布局与可读性

- 标题、坐标轴、单位、图例、直接标签和关键 mark 不得重叠、裁剪或跑出绘图区。
- 先减少次要标注和刻度，再换行或重排；不要靠缩到 11px 以下解决拥挤。
- 长类别名优先横向条形或换行。小多图在窄屏纵向堆叠，不把整组固定宽度图直接缩小。
- 响应式 SVG 使用合适的 `viewBox` 和容器宽度。若静态 SVG 无法在窄屏保持文字可读，
  可以让图表自己的容器横向滚动；页面主体不能整体横滚。
- 表格可以在自己的容器内横向滚动；卡片内部不要形成难发现的双向滚动区域。

## 数据与语义

- 抽查关键 mark、直接标签、tooltip/title 与等价表格中的数值一致；缺失值不能默认为零。
- 柱图从零基线开始；对数轴、指数化序列或截断范围必须在轴或副标题中明确标识。
- 系列顺序变化后颜色身份保持不变；图例、直接标签、线型或纹理与图中 mark 一一对应。
- 标题说明指标、粒度和时间范围，轴写单位；状态色带有文字或形状等第二编码。

## 交付前结论

只有在以下条件成立时才交付：主要问题能从图中直接回答；没有缺字、碰撞、裁剪或页面级
横向溢出；颜色校验中的 WARN 已有第二编码；静态 HTML 有紧凑表格等价视图。发现问题应
修改后重新查看受影响的输出，不要只在回复里提示用户自行处理。
