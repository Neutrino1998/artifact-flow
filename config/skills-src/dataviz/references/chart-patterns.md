# 图表模式

## 标记与布局

- 柱/条：默认偏细，保留留白；从共同基线开始。堆叠段之间留 1-2px surface 间隙。
- 折线：2px 左右，端点或重点点可加圆点；不要让粗线遮住网格和标签。
- 面积：只做轻填充，通常 8%-16% 透明度；大块高饱和面积会抢走数值判断。
- 网格/轴：浅色、实线、少量。网格是参照，不是视觉主体。
- 标题：写指标、粒度、时间范围。副标题解释口径，不要把口径藏进 tooltip。
- 容器高度要包含 x 轴标签；长标签优先横向条形或换行，不要让卡片内部出现滚动条。

## 标签与图例

- 两个及以上系列必须有图例或直接标签；单系列通常不需要单独图例。
- 直接标签要少：终点、极值、当前值、目标差距。不要每个点都贴数字。
- 标签放不下就移到外侧、图例、表格视图或说明里，不要裁剪文本。
- 文字用正文/次级/弱化墨色；不要把正文文字直接染成系列色。身份由旁边的色块、线段或点表达。
- 状态色必须配文字或图标。颜色不能单独承担“好/坏/危险”的语义。

## 静态 HTML artifact

ArtifactFlow 的 HTML artifact 不执行 script。图表应当用以下方式交付：

- 自包含 HTML：内联 CSS、内联 SVG 或 data URI；不依赖 CDN、远程字体、D3、Plotly、Recharts。
- SVG 中每个关键 mark 带 `<title>`，让浏览器原生提示和辅助技术能读到基本值。
- 数据表是图表的等价视图，至少在图后提供一个紧凑表格。
- CSS hover 可以增强视觉反馈，但不要把读数只放在 hover 后才出现的位置。
- 移动端：图表外层允许横向滚动表格，页面主体不能整体横滚。

## matplotlib 输出

- 使用已烤入的中文字体配置；不需要手动下载字体。
- 保存 PNG 时设置足够 DPI；报告型图片建议同时保留源码数据或表格。
- 深色背景图要重新选择色阶，不要把浅色模式颜色直接反相。

## 最后检查清单

- 是否有双轴、3D、彩虹渐变、过多类别、筛选换色？
- 色彩 WARN 是否已经用标签、图例、纹理或表格补足？
- 是否存在表格视图或可复制的数据摘要？
- 标题是否说明口径，轴单位是否明确？
- 小屏下文字是否溢出或遮挡？
