# 图形选择

在写图表代码前先回答：读者拿到图后要做什么判断？

| 数据任务 | 首选形式 | 颜色角色 | 避免 |
|---|---|---|---|
| 一个当前值、余额、总量 | 统计卡或大号数字 | 状态色只用于好坏 | 单柱图 |
| 多个头部指标 | KPI 行 | 文字层级 + 小趋势线 | 把 KPI 做成拥挤分组柱 |
| 类别大小比较 | 横向/纵向柱图 | 单一强调色，或分类色用于多系列 | 按数值给无序类别上渐变 |
| 时间趋势 | 折线图；单系列可用轻面积 | 单系列一色，多系列分类色 | 每个点都标数字 |
| 一个重点系列 vs 背景 | 重点色 + 其余灰色 | 强调色 | 给所有背景系列同等饱和色 |
| 正负、超过/低于目标 | 发散柱图或折线 + 基准线 | 发散色 | 双 y 轴 |
| 构成占比 | 堆叠条形；类别多时表格 + 图 | 分类色 | 过多扇区饼图 |
| 两个定量变量的关系 | 散点图；必要时加趋势和不确定区间 | 单色或少量分类色 | 用双轴折线暗示相关性 |
| 数值分布与离群值 | 直方图、箱线图或小提琴图 | 单一强调色 | 只报平均值或用饼图 |
| 地理位置或区域差异 | 点图或分级设色地图；排名更适合条形图 | 连续、发散或状态色 | 位置与问题无关时仍用地图 |
| 有序等级、漏斗、年龄段 | 单色有序色阶 | 有序色 | 彩虹色 |
| 前后对比 | Dumbbell、斜率图、并排条 | 两个明度步骤 | 复杂三维效果 |
| 类别超过 7 个且都重要 | 表格、小多图、Top N + Other | 少量强调 | 生成更多颜色 |

## 判断规则

- 一屏只允许一个主要问题。图表回答不了的问题不要塞进同一张图。
- 不要为了填满仪表盘而添加无决策用途的 KPI、卡片、控件或重复图表。
- 没有自然顺序的类别不要按数值染深浅；柱长已经表达数值。
- 系列颜色跟随实体，不跟随排序。筛选后幸存系列不能换色。
- 两个不同量纲不要放双轴。拆成两图，或把两条序列都转成同一基准指数。
- 类别太多时先改结构：折叠长尾、分面、小多图、表格。不要靠第 9 个颜色解决。
